# Nova Player releases

Install files for **Nova Player**, an IPTV player for Android TV and Android phones.
It ships with no channels: enter the login your own provider gives you.

## Install on Android TV / Fire TV
1. Install **Downloader** (by AFTVnews) from the TV's app store.
2. Allow Downloader to install unknown apps:
   - Google TV: *Settings → Apps → Security & restrictions → Unknown sources*
   - Android TV: *Settings → Device Preferences → Security & restrictions → Unknown sources*
   - Fire TV: *Settings → My Fire TV → Developer options → Install unknown apps*
3. Open Downloader, enter **6015298** and install.

Nova Player updates itself after that.

## Which file?
| File | Devices |
|---|---|
| `nova-player.apk` | TV boxes and most devices (32-bit ARM) |
| `nova-player-<ver>-arm64-v8a.apk` | Modern phones, including 64-bit-only ones |
| `nova-player-<ver>-armeabi-v7a.apk` | Same as `nova-player.apk` |
| `nova-player-<ver>-x86_64.apk` | Emulators |
